# Reolink Argus 4 Pro Outdoor Mount + Rain Hood

## Files
- `Argus4Pro_Outdoor_Mount.scad` — Parametric OpenSCAD model
- `Argus4Pro_Mount_with_Solar.scad` — Version with solar panel bracket

## How to use
1. Download and install free OpenSCAD: https://openscad.org
2. Open the `.scad` file in OpenSCAD
3. Adjust the parameters at the top if needed (cradle size, arm length, hood overhang, etc.)
4. Press F6 to render, then File → Export → Export as STL
5. Slice and print

## Recommended print settings
- **Material**: PETG or ASA (better for outdoor / UV / temperature swings than PLA)
- **Infill**: 30–40%
- **Walls**: 3–4 perimeters
- **Supports**: Usually not needed if oriented correctly
- **Layer height**: 0.2 mm
- **Orientation**: Print the wall plate flat on the bed

## Hardware needed
- 2× M6 or M8 screws + wall plugs (for concrete/wood)
- Optional: zip ties or additional screws if mounting the original camera ball joint into the cradle

## Notes for Estonia
- Mount solar panel separately (south-facing, steep angle)
- The hood helps with rain but is not fully sealed — the Argus 4 Pro is already IP66
- Check fit with your actual camera before final outdoor installation

Camera body size used: ≈ 128 × 87 × 80 mm
